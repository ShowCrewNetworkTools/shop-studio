# shop-studio
A private tool I built to manage my own Etsy shop. It creates and updates product listings, writes and optimises titles, tags and descriptions, prepares and uploads listing images, reads my shop's sales data to track performance, and sends messages to buyers about their orders. It connects to my shop via OAuth, is used solely by me for my own shop, and is not distributed to any other sellers. All data is stored securely and never shared with any third party.
